# 常见问题 FAQ

出错时看这里。功能怎么用见程序内的「设置 → 使用说明」（GitHub 上是 [MANUAL.zh.md](MANUAL.zh.md)），开发问题见 [DEVELOPMENT.md](DEVELOPMENT.md)。

---

## 悬浮窗与截取

**Q: Teams 实时字幕悬浮窗截不到（截出来是字幕底下的画面 / 黑块）？**
Teams 的「弹出字幕窗口」自带系统级反截屏，任何截图工具都截不到它。把字幕**固定在会议窗口内**（不要弹出），悬浮窗即可正常截取；配合自动刷新或全局重截键（默认 `Ctrl+Alt+Space`）挂机翻译。

**Q: 悬浮窗 / 划词识别到的内容已经是目标语言，为什么直接显示原文？**
默认行为：内容已是目标语言时不翻译、直接展示原文。整段基本都是目标语言才算：夹几个外文人名、术语（英文不超过 3 个词、中日韩不超过 4 个字）不影响；夹了一整句外文，或外文占多数，会整段翻成目标语言。想反向翻回源语言，设置 → 翻译设置 →「内容已是目标语言时」切到「自动互译」。

## 听译

**Q: 声音在放，字幕却不出？**
先看顶栏的**电平条**，它跟着实际收到的声音跳动：
- 条子不动 = 根本没收到声音。听译抓的是**这台电脑正在播放**的声音，不是麦克风；确认声音是从本机放出来的，且系统没静音（音量小没关系，静音就真的没有了）。选了「只听某个程序」时，还要确认出声的确实是那个程序，以及它没在音量合成器里被单独静音。
- 条子在跳但没字 = 声音收到了，但没有可识别的语音。纯音乐、掌声、太吵的环境都会这样，状态栏随后会提示「有声音但长时间未识别到清晰语音」；换一下识别语言试试。

**Q: 一句话被切成两半？**
断句靠停顿。说话中间明显停顿（比如逗号处换气）会被当成句子结束。这是字幕的通行做法，一行太长反而看不完。

**Q: 「只听某个程序」的下拉里没有我要的程序？**
列表里只出现**已经发过声音**的程序，先让它出声再来选。粒度到程序为止，做不到按网站区分：浏览器所有标签页在系统看来是同一个进程。Windows 10 没有这个功能，只能听全部声音。

**Q: 离线模式下 Ollama 填成局域网另一台机器的地址，为什么用不了？**
离线模式承诺不发任何网络请求，局域网也是网络。离线下本地翻译源只认本机地址（localhost、127.0.0.1、::1），主面板会提示「翻译源必须指向本机地址」。要用另一台机器上的模型，切回标准模式。

**Q: 听译占多少内存？**
会话运行时约 600–700MB（高精度档 1–1.6GB），**停止即全部释放**：识别引擎是独立进程，停止时直接退出。

## 朗读

**Q: 中英夹杂的句子读得怪？**
Kokoro 的中文音色读英文单词带口音，英文音色读中文亦然，这是模型本身的特点。装上 MeloTTS 后，中英夹杂的句子会自动改用它；纯中文、纯英文仍用你选的音色。指定了固定音色就不自动切换。

**Q: 日文、韩文能用神经语音读吗？**
目前的语音包只有中文和英文。读到其它语言时，这一句自动回落到系统语音（要系统装了对应语音），引擎设置不变。

**Q: 按下朗读要等多久？**
引擎热着时半秒左右出声，合成一句播一句。第一次朗读或一分钟没用之后要先加载语音包，多等 1.5–2.5 秒；悬浮窗开着时引擎不会卸载。

## 快捷键

**Q: 启动时提示"快捷键注册失败 / 被占用"？**
该快捷键被其他程序（输入法、截图工具、游戏平台等）先注册了。设置 → 界面外观 → 快捷键 里换一个组合。全局快捷键必须包含 `Ctrl` / `Alt` / `Win`（`F1`–`F24` 可单独使用），不允许绑裸键，免得把退格、空格这类打字键从整个系统里劫持掉；历史版本录入的裸键绑定会在启动时自动复位。

## 隐私模式

**Q: 离线模式下测试连接 / 检查更新 / 在线引擎全部失败？**
这是设计而非故障：离线模式**绝不触网**，由主进程按请求强制，在线翻译源、在线 OCR、更新检查、测试连接一律拦截。需要联网功能请切回标准模式。

**Q: 无痕模式下历史记录去哪了？**
无痕模式不写历史、不写磁盘缓存，会话结束即无痕。切回标准模式后恢复，之前的历史还在。

## OCR

**Q: 本地 OCR 提示"模型缺失"或下载失败？**
设置 → OCR 识别 → 本地 OCR 卡片里「重新下载基础模型」（约 25MB，来自 GitHub Release）。程序跟随系统代理；仍失败时检查代理能否访问 github.com。

**Q: 内置视觉模型为什么灰着、点不了「使用」？**
它只在「关于 → 显卡加速」打开时可用：CPU 上一张截图要好几秒，不实用。显卡关着时卡片会提示，已选中的情况下截图自动改走本地 OCR。

**Q: 选了内置视觉模型，为什么大多数截图还是本地 OCR 识别的？**
这是设计：选中它等于交给程序按截图分配。每次截图先过本地 OCR，简单的直接出结果，只有大图、多栏、表格、字号混杂或本地 OCR 没把握的才交给视觉模型。

**Q: 截图 OCR 的识别语言里为什么没有越南语 / 希腊语 / 泰语？**
识别语言取决于本地模型的字典里有没有那套字形。越南语和希腊语是故意不放的：模型没有声调和重音符号，识别出来会把它们全丢掉，而结果读着像正常文本，比认不出更容易骗人。泰语、希伯来语等本地完全没有模型。这些语言用 Windows OCR、在线 OCR 或视觉模型；本地引擎读不出时程序也会自动往下试。

**Q: 有 NVIDIA 显卡，想用更强的本地视觉模型？**
百度 Unlimited-OCR 的 vLLM 镜像是 OpenAI 兼容 API：本地起服务后，把 LLM Vision 引擎的地址指过去即可（设置 → OCR 识别 → LLM Vision）。

## 语言

**Q: 选了冷门语言，本地模型翻出来的东西明显不对？**
本地小模型遇到不认识的语言不会报错，而是流畅地输出错误内容。程序会先判断当前模型认不认识这门语言，不认识就优先走 Google 翻译；但这份判断基于模型名，改过名的微调模型可能认不出来，这种情况下把 Google 翻译在翻译源里往前排即可。

**Q: 中文界面下，荷兰语为什么在 H 而不是 D？**
字母索引跟随界面语言：中文界面按拼音首字母（荷兰语 = H），英文界面按英文名（Dutch = D）。切换界面语言后「上次停在哪个字母」会重新开始。

## 文档翻译

**Q: 右键菜单的「用 T-Translate 翻译」怎么没看到？**
菜单只挂在 PDF、DOCX、TXT 三种文件上。Windows 11 的右键先显示精简菜单，在「显示更多选项」（或按住 Shift 右键）里能找到。它随安装写入、随卸载清除；安装后资源管理器还没刷新的话，重启资源管理器或注销一次。

## 在线翻译源

**Q: 某个在线源一直失败，或报「模型不存在」？**
厂商会关停旧型号。先升到最新版，默认型号会跟着换；自己填过型号的，到设置 → 翻译源里把「模型」改成厂商现在提供的名字（2026-09：DeepSeek `deepseek-flash`、Gemini `gemini-flash-latest`、Claude `claude-sonnet-5`）。

**Q: DeepL 提示配额用尽？**
2026-07 起新注册的 DeepL API 是 Developer 计划，只有一次性 100 万字符，用完不按月恢复，要升级才能继续；更早申请的免费 Key（以 `:fx` 结尾）仍是每月 50 万字符。

## 内置模型

**Q: 模型文件放进去了，卡片显示「文件不符」？**
文件名和大小对，但内容与官方哈希不一致，通常是下载不完整或版本不对。重新从官方或镜像链接下载覆盖，再点「重新扫描」。

**Q: 为什么翻译比云端源慢？**
1.7B 模型纯 CPU 大约每秒 20 个字，首字要等提示词处理完，通常半秒内；开了「关于 → 显卡加速」后快十倍左右。设置 → 本地模型里的「自检」会给出你机器上的实际数字，低于每秒 8 个字会提示开显卡。模型 5 分钟不用自动卸载，下一次用会多等一两秒载入。

**Q: 选了 Hy-MT2 之后「总结」为什么走了别的源？**
Hy-MT2 是只会翻译的模型，给它一段指令它会把指令翻出来。所以选它时，AI 动作自动改走翻译源列表里下一个能对话的大模型源；要 AI 动作也用本地模型，选回 Qwen3-1.7B。

## 性能

**Q: 任务管理器里内存占用几百 MB 正常吗？**
正常。识别 / 翻译进行中，本地 OCR 的推理内存池会上探（数百 MB 量级）；空闲一段时间后回落。持续增长且不回落才是异常，欢迎带日志反馈（设置 → 关于 → 打开日志目录）。

## 更新与安装

**Q: 如何更新版本？**
设置 → 关于 → 检查更新，支持差分下载。手动下载去 GitHub Releases 取最新安装包。

**Q: 重装后设置、历史丢了？**
正常卸载和升级不会丢：设置、历史和模型放在安装目录的 `data` 与 `models` 文件夹里，卸载时会被移到旁边保留、重装时搬回。如果你手动删过安装目录旁边的 `T-Translate-data`，那就是删掉了。API 密钥和历史记录是用这台电脑的系统密钥加密的，换电脑或重装系统后可能打不开——要带走，用历史页的导出和隐私页的迁移包（见使用说明第 7 章）。

**Q: 换电脑怎么把配置带过去？**
设置 → 隐私模式 → 迁移 → 导出迁移包，得到一个 JSON 文件；新机上导入，可勾选只要设置、术语库、收藏或自定义语言中的哪几样。API 密钥和模型文件不在包里：密钥重新填写，模型文件夹可以整个复制过去。

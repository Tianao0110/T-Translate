# 常见问题 FAQ

使用中的高频问题与已知边界。功能教程见 [README](../README.zh-CN.md)，开发问题见 [DEVELOPMENT.md](DEVELOPMENT.md)。

---

## 悬浮窗与截取

**Q: Teams 实时字幕悬浮窗截不到（截出来是字幕底下的画面/黑块）？**
Teams 的「弹出字幕窗口」自带系统级反截屏（WDA 排除捕获，任何截图工具都截不到它）。解法：把字幕**固定在会议窗口内**（不要弹出），悬浮窗即可正常截取；配合自动刷新（工具栏刷新按钮选间隔）或全局重截键（默认 `Ctrl+Alt+Space`，可改）实现零焦点挂机翻译。

**Q: 悬浮窗/划词识别到的内容已经是目标语言，为什么直接显示原文？**
这是默认行为（v0.3.1 后可配置）：内容已是目标语言时无需翻译，直接展示原文、不消耗 API 调用。若希望此时反向翻回源语言，设置 → 翻译设置 →「内容已是目标语言时」切换为**自动互译**。

## 听译

**Q: 听译按钮是灰的点不动？**
识别模型还没装。设置 → 音频 → 听 → 下载基础模型（153MB）。装完悬浮窗那个按钮立刻可点，不用重开窗口。

**Q: 草稿引擎那 168MB 值得装吗？**
只影响中英**是否边说边出字**：装了约 0.6 秒出首字、每 0.3 秒刷新；不装则整句说完（约 0.4 秒后）才出字。日/韩/粤本来就走后一条路，只听这三种语言不用装。定稿的准确度两者完全一样。

**Q: 声音在放，字幕却不出？**
先看顶栏状态右边那条**电平条**：它跟着实际收到的声音跳动（约 0.1 秒一次，比出字快得多）。
- 条子不动 = 根本没收到声音。听译抓的是**这台电脑正在播放**的声音，不是麦克风；确认声音是从本机放出来的，且系统没静音（音量开得小没关系，程序会按系统音量自动补回来；静音就真的没有了）。选了「只听某个程序」时，还要确认出声的确实是那个程序，以及它没有在音量合成器里被单独静音（那种情况下我们也拿不到声音）。
- 条子在跳但没字 = 声音收到了，只是没有可识别的语音。纯音乐、掌声、太吵的环境都会这样，状态栏随后会提示「有声音但长时间未识别到清晰语音」。

**Q: 能只听某一个程序吗？比如只听播放器不听 QQ 提示音**
可以（Windows 11）。工具栏第一个下拉就是声音来源：默认全部声音，展开就是程序名，选一个即只听它。列表里只会出现**已经发过声音**的程序——没开过音频流的进程在系统层面根本不存在，所以先让它出声再来选。前面带 ▶ 的是此刻正在响的。选中的程序退出后会自动切回全部声音并提示一下。
两个边界要知道：①粒度到「程序」为止，**做不到按网站区分**——浏览器所有标签页共用同一个音频进程，系统看来就是一个 chrome.exe；②Windows 10 没有这个 API（微软要求 build 20348 以上，消费版 Win10 最高 19045），只能听全部声音，下拉里会写明。

**Q: 听译会不会顺便截我的屏？**
不会，而且现在连请求都不会发。v0.4.1 之前，取系统声音走的是浏览器那套「共享屏幕」接口，它强制要求一条视频轨（我们拿到即刻停掉，从不读像素）。现在换成了直接调用 Windows 的音频接口，整个流程与屏幕无关。

**Q: 一句话被切成两半？**
断句靠停顿。说话时中间明显停顿（比如逗号处换气）会被当成句子结束。这是字幕的通行做法——一行太长反而看不完。

**Q: 无痕模式下听译能用吗？**
能用。无痕模式下听译不写会话日志（标准模式下那份只有时长、耗时等指标的本地调试日志），字幕照常出、照常翻译；程序自己的运行日志也只留错误一级。

**Q: 听译占多少内存？**
会话运行时约 600–700MB（两个模型都装时偏上限），**停止即全部释放**——识别引擎是独立进程，停止时直接退出，不驻留。

**Q: 模型下载到哪了？想删掉腾空间**
安装目录下的 `models` 文件夹（装在哪个盘就占哪个盘）。设置 → 音频 → 听（识别模型）或 读 → 语音包 里每个包都能单独卸载，卸载即整目录删除。v0.4.0 之前下载的模型留在 `%APPDATA%\t-translate\` 下，照常可用，想腾地方可手动搬到安装目录的 `models` 里。

## 朗读

**Q: 「神经语音」在哪？语音引擎里只有系统语音**
设置 → 音频 → 读 → 语音包，先下载一个包（Kokoro 341MB 或 MeloTTS 157MB），装好后「朗读」页的语音引擎里才能选「神经语音」。合成全程在本机，不联网；系统语音不用下载，随时可以切回去。「当前朗读」那一行写着现在到底是本机哪个引擎还是 API 在读。

**Q: 中英夹杂的句子读得怪？**
Kokoro 的中文音色读英文单词带口音，英文音色读中文亦然，这是模型本身的特点。装上 MeloTTS 之后，中英夹杂的句子会自动改用它（它就是按混说训练的）；纯中文、纯英文仍用你选的音色。指定了音色的话就一直用那个音色，不自动切换。

**Q: 日文、韩文能用神经语音读吗？**
目前的语音包只有中文和英文。读到其它语言时，这一句自动回落到系统语音（要系统装了对应语音），引擎设置不变，下一句中英文照旧走神经语音。

**Q: 想用 IndexTTS、GPT-SoVITS、CosyVoice 这类引擎？**
它们不内置（Python 加显卡的模型），走「外接语音服务」：本地起一个 OpenAI 兼容的语音服务（这些项目都有现成的兼容服务端，kokoro-fastapi 也行），在设置 → 音频 → 读 → 朗读里选「外接服务」填地址。OpenAI 本身同样能填。密钥存在系统加密库里；离线模式下这个引擎不可用。

**Q: 听译的字幕能读出来吗？读的时候会不会被自己转写回去？**
鼠标停在某行字幕右侧出现喇叭键，点它读这行译文（没有译文读原文），用的是「音频 → 读」里设的引擎和音色。朗读期间程序自动暂停收音（顶部显示「朗读中 · 暂停收音」），自己的声音不会变成新字幕；代价是这几秒里视频说的话也会漏掉。

**Q: 按下朗读要等多久？**
装了语音包、引擎已经热着时，半秒左右出声，合成一句播一句。第一次朗读（或一分钟没用之后）要先加载语音包，多等 1.5–2.5 秒；悬浮窗开着时引擎不会卸载。

## 快捷键

**Q: 启动时提示"快捷键注册失败/被占用"？**
该快捷键被其他程序（输入法、截图工具、游戏平台等）先注册了。设置 → 界面外观 → 快捷键里换一个组合；全局快捷键必须包含 `Ctrl`/`Alt`/`Win` 修饰键（`F1`-`F24` 可单独使用），不允许绑裸键——避免把退格、空格这类打字键从整个系统里劫持掉。历史版本录入的裸键绑定会在启动时自动复位为默认值。

## 隐私模式

**Q: 离线模式下测试连接/检查更新/在线引擎全部失败？**
这是设计而非故障：离线模式承诺**绝不触网**，由主进程按请求强制（在线翻译源、在线 OCR、更新检查、测试连接一律拦截），渲染层无法绕过。需要联网功能请切回标准模式。

**Q: 无痕模式下历史记录去哪了？**
无痕（SECURE）模式不写历史、不写磁盘缓存，会话结束即无痕。切回标准模式后恢复记录行为。

## OCR

**Q: 本地 OCR 提示"模型缺失"或下载失败？**
设置 → OCR 识别 → 本地引擎卡片里重新下载基础模型（约 25MB，来自 GitHub Release）。网络代理环境下应用跟随系统代理；仍失败时检查代理能否访问 github.com。

**Q: 有 NVIDIA 显卡，想用更强的本地视觉模型做 OCR？**
百度 Unlimited-OCR 的 vLLM 镜像是 OpenAI 兼容 API：本地起服务后，把 LLM Vision 引擎的端点指过去即可零改动直连（设置 → OCR 识别 → LLM Vision）。

## 语言

**Q: 语言列表里找不到我要的语言？**
选择器最下面有「添加自定义语言」。填一个名字即可（另可单独指定"发给模型的名字"——本地模型可能只认「藏语」不认 Tibetan）。注意这类语言**不在谷歌翻译的支持范围内**，能否翻译完全取决于你当前使用的大模型认不认识它，结果可能不准确。已添加的可以在 设置 → 翻译设置 里删除。

**Q: 中文界面下，荷兰语为什么在 H 而不是 D？**
字母索引跟随界面语言：中文界面按拼音首字母（荷兰语 = hélán = H），英文界面按英文名（Dutch = D）。所以切换界面语言后，"上次停在哪个字母"会重新开始——同一个字母在两种索引里指向的组不一样。

**Q: 截图 OCR 的识别语言里为什么没有越南语 / 希腊语 / 泰语？**
识别语言和翻译语言是两回事：翻译支持 134 种，识别取决于本地模型的字典里有没有那套字形。越南语和希腊语是故意不放的——它们看起来像能读（越南语就是拉丁字母），但模型没有叠调符号，识别出来会把声调全丢掉，而结果读着像正常文本，比认不出更容易骗过人。泰语、希伯来语等则是本地完全没有模型。这些语言可以改用 Windows OCR、在线 OCR 或视觉大模型，程序现在也会在本地引擎读不出东西时自动往下试这些引擎。

**Q: 选了冷门语言，本地模型翻出来的东西明显不对？**
本地小模型遇到不认识的语言不会报错，而是流畅地输出错误内容。程序现在会先判断当前模型认不认识这门语言，不认识就优先走谷歌翻译。但这份判断基于模型名，改过名的微调模型可能认不出来——这种情况下把谷歌翻译在设置里往前排即可。

## 文档翻译

**Q: 「术语检查」和术语库的自动替换有什么区别？**
自动替换发生在每段翻译完成时；「术语检查」是翻译完之后在工具栏手动触发的一次核对，
找出术语库里有、但译文里仍是原文的词，弹窗确认后全部替换。替换过的词在段落里双向
高亮（原文的词和译文的词都标出来），点高亮可以看原词，也可以只撤销那一处。零模型
调用、纯文本匹配，只使用当前目标语言的术语。

**Q: 右键菜单的「用 T-Translate 翻译」怎么没看到？**
菜单只挂在 PDF、DOCX、TXT 三种文件上。Windows 11 的右键先显示精简菜单，
在「显示更多选项」（或按住 Shift 右键）里能找到。它随安装程序写入、随卸载
清除；若安装后资源管理器还没刷新，重启资源管理器或注销一次即可。

## AI 功能（讲解 / 总结）

AI 功能只有两个概念：**「讲解」帮你看懂这一段，「总结」帮你读完一长篇**。
界面上出现的「总结全文」「总结已讲解段落」都是总结在文档里的作用域变体。

**Q: 为什么看不到「总结」按钮？**
三种可能：① 当前翻译源只会翻译不能对话（DeepL / Google 翻译 / 微软 / 百度），
设置 → 翻译源里这类卡片带「无 AI 动作」标记，换成大模型源即可（LM Studio /
Ollama / OpenAI / Claude / Gemini / DeepSeek）；② 内容太短——总结只对长段出现
（中文约 150 字、英文约 120 词以上）；③ 悬浮窗当前是散点排版，散点是零散标签，
没有总结价值。

**Q: 讲解和总结有什么区别？**
总结是"读完给要点"，讲解是"讲清楚这段在说什么"。悬浮窗左上角的讲解模式开关
打开后，截图**不再翻译**、直接讲解，也不卡长度；文档翻译页每个段落也有讲解按钮。

**Q: 总结完在哪看？会保存吗？**
就在原来那张卡/那个窗口里折叠展开，再点一次收起。非无痕模式下会作为附属存进历史
（历史卡片右上角有标记，双击详情可见，能单独删掉总结保留翻译）。讲解的结果
也保存：作为独立条目进历史（原文 + 讲解，卡片带「AI」徽章），同一段重新
讲解会替换旧条目，不计入翻译次数统计；「恢复编辑」只回填原文。

**Q: 会把我的截图发到云端吗？**
只有配了视觉模型且走路径 B 时才发截图，按钮悬停提示会写明。离线模式下强制要求
视觉模型端点在本机，截图不会离开这台电脑；无痕模式不留任何 AI 结果。

**Q: 文档翻译里怎么用？**
每个段落右上角有一个「AI」小徽章，点它讲解这一段，结果展开在译文下方；再点一下收起，不会重新生成。它读的是**原文**，所以还没翻译的段落也能用。讲解过两段以上后，工具栏会出现「整理笔记」，把这些讲解汇总成一份连贯笔记——**它只覆盖你点开过的段落，不是全文摘要**，面板上也写明了这一点。讲解笔记和整理笔记会随翻译进度一起保存，7 天内重新打开同一个文件可以恢复；无痕模式下不保存。

**Q: 能自己加动作吗？**
能。设置 → AI 动作 → 导入配置文件，一份 JSON 就是一个动作（提示词配置，不是代码）。
字段不合规会当场拒收并说明原因。

## 性能

**Q: 任务管理器里内存占用几百 MB 正常吗？**
正常。识别/翻译进行中，本地 OCR 的推理内存池会上探（数百 MB 量级）；空闲一段时间后回落到 ~200MB 基线。持续增长且不回落才是异常，欢迎带日志反馈（设置 → 关于 → 打开日志目录）。

## 更新与安装

**Q: 如何更新版本？**
设置 → 关于 → 检查更新，支持差分下载（只下变更部分）。手动下载则去 GitHub Releases 取最新安装包。

**Q: 快捷键/设置在重装后丢了？**
设置存于 `%APPDATA%\T-Translate\`（`config.json` 等），重装不清除该目录即可保留。v0.3.8 起卸载程序会询问是否同时删除全部用户数据——想保留就选「否」（默认），静默卸载与自动更新不会删。API 密钥经 Windows DPAPI 加密绑定当前用户，换机不可迁移、需重新填写（这是加密设计，不是 bug）；翻译历史 v0.3.8 起同样加密绑定当前用户，直接拷贝数据目录到别的电脑读不出历史——要带走历史，用历史页的导出/导入功能（迁移包不含历史）。

**Q: 换电脑怎么把配置带过去？**
设置 → 隐私 → 迁移 → 导出迁移包，得到一个 JSON 文件；到新机上同一位置导入，
可勾选只要设置、术语库、收藏或自定义语言中的哪几样，重复条目自动跳过。
API 密钥和已下载的模型文件不在包里：密钥按上一条的加密设计需重新填写，
模型在新机上重新下载。

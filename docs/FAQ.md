# 常见问题 FAQ

使用中的高频问题与已知边界。功能教程见 [README](../README.zh-CN.md)，开发问题见 [DEVELOPMENT.md](DEVELOPMENT.md)。

---

## 悬浮窗与截取

**Q: Teams 实时字幕悬浮窗截不到（截出来是字幕底下的画面/黑块）？**
Teams 的「弹出字幕窗口」自带系统级反截屏（WDA 排除捕获，任何截图工具都截不到它）。解法：把字幕**固定在会议窗口内**（不要弹出），悬浮窗即可正常截取；配合自动刷新（工具栏刷新按钮选间隔）或全局重截键（默认 `Ctrl+Alt+Space`，可改）实现零焦点挂机翻译。

**Q: 悬浮窗/划词识别到的内容已经是目标语言，为什么直接显示原文？**
这是默认行为（v0.3.1 后可配置）：内容已是目标语言时无需翻译，直接展示原文、不消耗 API 调用。若希望此时反向翻回源语言，设置 → 翻译设置 →「内容已是目标语言时」切换为**自动互译**。

## 快捷键

**Q: 启动时提示"快捷键注册失败/被占用"？**
该快捷键被其他程序（输入法、截图工具、游戏平台等）先注册了。设置 → 界面外观 → 快捷键里换一个组合；全局快捷键必须包含 `Ctrl`/`Alt`/`Win` 修饰键（`F1`-`F24` 可单独使用），不允许绑裸键——避免把退格、空格这类打字键从整个系统里劫持掉。历史版本录入的裸键绑定会在启动时自动复位为默认值。

## 隐私模式

**Q: 离线模式下测试连接/检查更新/在线引擎全部失败？**
这是设计而非故障：离线模式承诺**绝不触网**，由主进程按请求强制（在线翻译源、在线 OCR、更新检查、测试连接一律拦截），渲染层无法绕过。需要联网功能请切回标准模式。

**Q: 无痕模式下历史记录去哪了？**
无痕（SECURE）模式不写历史、不写磁盘缓存，会话结束即无痕。切回标准模式后恢复记录行为。

## OCR

**Q: 本地 OCR 提示"模型缺失"或下载失败？**
设置 → OCR 识别 → 本地引擎卡片里重新下载基础模型（约 25MB，来自 GitHub Release）。网络代理环境下应用跟随系统代理；仍失败时检查代理能否访问 github.com。

**Q: 有 NVIDIA 显卡，想用更强的本地视觉模型做 OCR？**
百度 Unlimited-OCR 的 vLLM 镜像是 OpenAI 兼容 API：本地起服务后，把 LLM Vision 引擎的端点指过去即可零改动直连（设置 → OCR 识别 → LLM Vision）。

## 性能

**Q: 任务管理器里内存占用几百 MB 正常吗？**
正常。识别/翻译进行中，本地 OCR 的推理内存池会上探（数百 MB 量级）；空闲一段时间后回落到 ~200MB 基线。持续增长且不回落才是异常，欢迎带日志反馈（设置 → 关于 → 打开日志目录）。

## 更新与安装

**Q: 如何更新版本？**
设置 → 关于 → 检查更新，支持差分下载（只下变更部分）。手动下载则去 GitHub Releases 取最新安装包。

**Q: 快捷键/设置在重装后丢了？**
设置存于 `%APPDATA%\T-Translate\`（`config.json` 等），重装不清除该目录即可保留；API 密钥经 Windows DPAPI 加密绑定当前用户，换机不可迁移、需重新填写（这是加密设计，不是 bug）。

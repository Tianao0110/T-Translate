# T-Translate 使用说明

本说明书随程序分发，在「设置 → 使用说明」里可以离线查看；GitHub 上的同一份文件内容相同。

## 0. 开始使用

### 0.1 安装与首次启动

- 安装包是 `T-Translate-Setup-x.y.z.exe`，只支持 Windows x64。安装向导里可以改安装目录。
- 程序的设置、历史和缓存放在安装目录下的 `data`，下载的模型放在 `models`。卸载时这两个文件夹会被移到安装目录旁边的 `T-Translate-data` 保留，下次安装或升级时自动搬回。
- 安装后，资源管理器里右键 `.pdf`、`.docx`、`.txt` 文件会多出一项「用 T-Translate 翻译」，点它直接进入文档翻译。
- 第一次启动会看到欢迎页，四张卡片介绍划词翻译、截图翻译、悬浮窗口和文档翻译，点「开始使用」进入主窗口。
- 翻译源默认启用四个，按顺序尝试：内置模型、LM Studio、Ollama、Google 翻译。内置模型要先把模型文件放进模型文件夹（见第 5 章）；LM Studio 和 Ollama 要在本机运行着；三个都没有时，联网即可用 Google 翻译。翻译面板顶部出现「还没有可用的翻译源」时，点「去设置」。
- 设置页默认是「简洁」目录，只列常用项；点左栏底部的「完整」看全部设置。
- 主窗口的关闭按钮不会退出程序，只是收进托盘。要退出，用托盘菜单里的「退出」，或按 Ctrl+Q。

### 0.2 托盘常驻与托盘菜单

- 程序运行时，任务栏托盘常驻一个图标。单击图标开关划词翻译，开着时鼠标悬停提示会带一个 ✓；双击图标显示主窗口；右键打开菜单。
- 菜单项：截图翻译、悬浮窗口、划词翻译、设置、退出。
- 开机自启：设置 → 界面外观 → 启动 → 开机自启动。自启后程序在后台运行，不弹主窗口；再打开「启动后自动开启划词翻译」，开机后不用碰托盘，选中文字就能翻译。

### 0.3 全局快捷键一览

这五个快捷键在任何程序里都有效：

- **Alt+Q**：截图翻译
- **Ctrl+Shift+W**：显示 / 隐藏主窗口
- **Ctrl+Alt+G**：打开 / 关闭悬浮窗口
- **Ctrl+Shift+T**：开关划词翻译
- **Ctrl+Alt+Space**：让悬浮窗口重新截译一次，悬浮窗口不会抢走当前程序的焦点

在 设置 → 界面外观 → 快捷键 里可以改。全局快捷键必须带 Ctrl、Alt 或 Win 键，F1 到 F24 可以单独用。启动时如果某个快捷键被别的程序占用，会弹提示，改一个别的组合即可。全部快捷键见第 6 章。

### 0.4 三种隐私模式

在 设置 → 隐私模式 里切换，三种模式一句话：

- **标准模式**：功能全开，自动保存历史记录。
- **无痕模式**：不保存历史、收藏和缓存，不写会话日志，关闭窗口即清除；不能导出和导入；不使用 Windows OCR，因为它要把截图写成临时文件。
- **离线模式**：不发出任何网络请求。只用本地翻译源（内置模型、LM Studio、Ollama）和本地 OCR 引擎；在线翻译源、在线 OCR、外接朗读服务、模型下载和检查更新全部禁用；历史记录照常保存。

## 6. 快捷键总表

### 6.1 全局快捷键

在任何程序里都有效，可在 设置 → 界面外观 → 快捷键 里修改：

- **Alt+Q**：截图翻译
- **Ctrl+Shift+W**：显示 / 隐藏主窗口
- **Ctrl+Alt+G**：打开 / 关闭悬浮窗口
- **Ctrl+Shift+T**：开关划词翻译
- **Ctrl+Alt+Space**：悬浮窗口重新截译（不抢焦点）

### 6.2 主窗口

- **Ctrl+1 到 Ctrl+5**：切换到翻译、历史、收藏、设置、文档五个页面
- **Ctrl+Enter**：在原文框里按下即翻译
- **Ctrl+F**：在历史、收藏、文档页里定位到搜索框
- **F11**：全屏，再按一次或按 Esc 退出
- **Ctrl+Q**：退出程序

### 6.3 悬浮窗口

- **空格**：截译当前区域；已有结果时清空
- **Esc**：按顺序做一件事：退出粘性穿透 → 关闭最近记录面板 → 清掉散点面板 → 关闭窗口
- **按住 Alt**：临时穿透，鼠标点击落到窗口下面的程序上，松开恢复
- **Ctrl+H**：打开 / 关闭最近记录面板
- **双击某个散点面板**：把它脱离成独立的小窗口

### 6.4 划词翻译

- **CapsLock**：在 设置 → 划词翻译 里开启「CapsLock 直出模式」后，CapsLock 灯亮着时划词直接弹出翻译卡片，不再经过小图标；灯灭恢复普通流程。CapsLock 本身的大写功能不受影响。

# T-Translate 使用说明

本说明书随程序分发，在「设置 → 使用说明」里可以离线查看；GitHub 上的同一份文件内容相同。

## 0. 开始使用

### 0.1 安装与首次启动

- 双击安装包安装，可以自己选安装位置。
- 卸载不会删掉你的设置、历史记录和下载好的模型，重新安装后还在。
- 安装后，右键 .pdf、.docx、.txt 文件会多出一项「用 T-Translate 翻译」，点它直接开始翻译这个文件。
- 第一次打开会看到一页功能介绍，点「开始使用」进入主窗口。
- 装好就能用 Google 翻译，需要联网。想不联网也能翻译，把内置模型的文件放进模型文件夹（见第 5 章），或者在本机运行 LM Studio 或 Ollama。翻译面板上方出现「还没有可用的翻译源」时，点「去设置」。
- 设置页默认只显示常用项，点左下角的「完整」可以看到全部设置。
- 点主窗口右上角的关闭，程序会缩到托盘继续运行。要彻底退出，右键托盘图标选「退出」。

### 0.2 托盘图标

- 单击：开关划词翻译。开着时，鼠标放到图标上的提示里带一个 ✓。
- 双击：打开主窗口。
- 右键菜单：截图翻译、悬浮窗口、划词翻译、设置、退出。
- 想让程序开机自动运行：设置 → 界面外观 → 启动，打开「开机自启动」。再打开「启动后自动开启划词翻译」，开机后不用碰托盘，直接就能划词。

### 0.3 全局快捷键

这五个快捷键在任何程序里都能按：

- **Alt+Q**：截图翻译
- **Ctrl+Shift+W**：显示 / 隐藏主窗口
- **Ctrl+Alt+G**：打开 / 关闭悬浮窗口
- **Ctrl+Shift+T**：开关划词翻译
- **Ctrl+Alt+Space**：让悬浮窗口再截译一次

都可以在 设置 → 界面外观 → 快捷键 里改。如果启动时提示某个快捷键被别的程序占用了，换一个组合就好。全部快捷键见第 6 章。

### 0.4 三种隐私模式

在 设置 → 隐私模式 里切换：

- **标准模式**：功能全开，自动保存历史记录。
- **无痕模式**：什么都不保存，关掉窗口就清空。
- **离线模式**：完全不联网，只用本机的翻译源和识别引擎。

想看每个功能在三种模式下的差别，点隐私模式页里的「详细」。

## 1. 主窗口

主窗口顶部有五个页面：翻译、历史、收藏、设置、文档。点图标切换，或按 Ctrl+1 到 Ctrl+5。

### 1.1 翻译面板

**语言**

- 左边选源语言，右边选目标语言。源语言留「自动检测」即可，程序会自己判断。
- 中间的交换按钮把两边语言对调。
- 语言列表按首字母分组，右侧有字母条可以快速定位；最近用过的语言在最上面。

**语气**

语言下面有三个语气按钮：自然（日常口语）、精确（技术、学术）、正式（商务、公文）。选一个，翻译时就按这个语气来。

**原文框**

- 直接输入或粘贴文字。按 Ctrl+Enter 翻译，或点中间的「翻译」按钮。
- 打开了「自动翻译」（设置 → 翻译设置）的话，停止输入片刻会自动翻译。
- 框上方的按钮：截图识别、导入图片、粘贴、清空、朗读原文。
- 把图片或 .txt / .md 文件拖进原文框也可以：图片会先识别文字，文本文件直接读入。
- 剪贴板里是图片时，点「粘贴」会自动识别里面的文字。

**译文框**

- 译文可以直接编辑。改过之后，右上角会出现版本切换，能在原始译文和你改过的版本之间来回看。
- 框上方的按钮：复制、风格改写、收藏、朗读译文。内容够长时还会出现「总结」（见 1.5）。
- **风格改写**：从风格库里挑一条参考文本，让模型按它的语气重写当前译文，可以选改写强度。风格库在收藏页里维护，见 1.3。
- **收藏**：弹出收藏对话框，可以填标签和笔记；有能对话的翻译源时，程序会自动建议标签和摘要。勾上「标记为风格参考」会存进风格库。

**术语**

- 术语库里有对应的词而译文没按它来的时候，译文下方会出现提示，可以一键应用、忽略这次，或者对这条术语「不再提示」。
- 术语库里的词会在翻译时自动替换，替换后底部弹一条提示，里面有「撤销」。

### 1.2 历史记录

- 每次翻译自动保存在这里；无痕模式下不保存。
- 顶部可以搜索、按时间（今天 / 本周 / 本月）和来源（主界面 / 划词 / 截图 / 悬浮窗）筛选。
- 卡片视图和表格视图可切换；表格可以按时间、语言、长度排序。
- 点一条记录可以在原文和译文之间切换，双击看详情。带 AI 结果的记录会有标记，详情里能看到。
- 每条记录可以复制原文或译文、收藏、恢复到翻译面板继续编辑、删除。
- 「选择」进入多选，空格选中，Esc 退出，可以批量删除。
- 「导出」把历史保存成文件，「导入」读回来；无痕模式下不能导入。
- 搜索结果里可以用 ↑↓ 移动、Enter 复制译文。
- 想让旧记录自动清理，去 设置 → 隐私模式 → 数据管理，设「自动删除历史记录」的天数。

### 1.3 收藏

- 在翻译面板、历史记录或划词、悬浮窗里点星标收藏。
- 左侧是文件夹：默认有工作、学习、生活三个，可以新建、删除；另外两个是固定的：**术语库**和**风格库**。
- 每条收藏可以编辑标签和笔记，可以移动到别的文件夹，可以用 AI 生成标签。
- **术语库**：放进去的词条会在以后翻译时自动沿用你的译法。「导入术语」「导出术语」支持 JSON、CSV 和 TBX 文件。文档翻译里的「术语检查」用的也是这里的词条。
- **风格库**：翻译面板里「风格改写」的参考来源。收藏时勾「标记为风格参考」，或在收藏卡片上切换，都会移进风格库。

### 1.4 文档翻译

- 支持 9 种格式：纯文本、Markdown、SRT 字幕、WebVTT 字幕、PDF、Word（.docx）、CSV、JSON、EPUB。单个文件最大 20 MB。
- 把文件拖进来或点击选择。在资源管理器里右键 .pdf / .docx / .txt 选「用 T-Translate 翻译」也会直接打开到这里。
- 加密的 PDF 会要求输入密码。扫描版 PDF 没有文字层，程序会逐页做文字识别，需要先在设置里配好 OCR 引擎。
- 文档按段落显示，可以选「上下对照」或「左右对照」。左侧的大纲能跳到各个标题。
- 点「开始翻译」逐段翻译，可以暂停、继续、停止。失败的段落可以单独重试，也可以「重试失败」一次重试全部。
- 每段译文都可以编辑、重新翻译、复制。
- 底部「并发」开关：开着同时翻译多段，速度快；本地模型不稳时关掉，改为逐段翻译。
- 底部「术语」开关：控制翻译时是否套用术语库。
- 翻译到一半关掉程序也没关系，下次打开同一个文件会提示「恢复进度」。
- **导出**：双语或仅译文的 TXT、Markdown、Word；PDF 走打印保存；字幕文件可以导出 SRT 或 VTT。
- **讲解与总结**：每段旁边有「讲解这一段」；讲解过两段以上后可以「总结已讲解段落」；「总结全文」会先逐段讲解再汇总，长文档要等一会儿，用在线 API 会按用量计费。
- **术语检查**：对照术语库检查全文用词是否一致，列出可替换的地方，可以逐条撤销。不调用模型。
- 右下角的统计按钮显示段落数、字符数、用时等；文档翻译完成时如果窗口在后台，会弹系统通知。

### 1.5 AI 动作

AI 动作是在翻译之外再做一层理解，比如把一段内容总结成要点、把一块内容讲解清楚。

- 内置两个：**总结**（出现在翻译面板、划词、悬浮窗，内容够长时才出现）和**讲解**（悬浮窗的讲解模式、文档翻译的每一段）。
- 需要能对话的翻译源：内置模型的通用模型、LM Studio、Ollama、OpenAI、DeepSeek、Gemini、Claude 这类。Google 翻译、DeepL、百度、微软这类传统翻译源做不了，翻译源卡片上会标「无 AI 动作」。
- 结果显示在译文下方，可以折叠；同时挂在对应的历史记录上，历史详情里能再看。
- 配置了视觉模型时，截图来的内容会把图片直接交给视觉模型看，按钮上会提示「会把这张截图发给视觉模型」。
- 「总结」出现的字数门槛、导入更多动作，都在 设置 → AI 动作 里。

### 1.6 标题栏与窗口行为

- 标题栏右侧是最小化、最大化、关闭。关闭只是缩到托盘，程序继续运行。
- 拖标题栏移动窗口，F11 全屏。
- 底部状态栏显示：当前状态（就绪 / 翻译中）、当前语言对、今日翻译次数、版本号。
- 切换页面时各页的内容都保留，比如文档翻译进行中可以切去历史再切回来。

## 2. 划词翻译

在任何程序里选中文字，就能翻译。

**打开和关闭**

- 单击托盘图标、按 Ctrl+Shift+T，或在 设置 → 划词翻译 里打开「启用划词翻译」。开着时托盘图标的提示带 ✓。
- 程序刚启动时划词翻译是关着的。想开机自动打开，见 0.2。

**怎么用**

1. 用鼠标拖选一段文字，或双击、三击选词选段。
2. 松开鼠标，旁边出现一个小图标。几秒不点它会自己消失（时间可在设置里改）。
3. 点图标，弹出翻译卡片。
4. 卡片上的按钮：显示原文、复制译文、朗读、关闭。右键卡片也能关闭。内容够长时还会出现「总结」。
5. 卡片过一会儿自动消失，鼠标放在上面就不会消失。

**固定卡片**

- 拖动卡片，它就固定住不再消失，下次划词会弹新的卡片。固定的卡片右键关闭，最多同时固定 8 个。

**CapsLock 直出**

- 在 设置 → 划词翻译 里打开「CapsLock 直出模式」后，CapsLock 灯亮着时，选中文字直接弹出翻译卡片，不用点图标。灯灭就回到平时的流程，打大写字母不受影响。
- 在终端类程序（Windows Terminal、命令提示符等）里不会直出，仍然先出图标。

**相关设置**（设置 → 划词翻译）

- 按钮自动消失时间、默认显示原文、复制后自动关闭。
- 字符数限制：选中内容太短或太长不触发翻译，默认 2 到 2000 个字符。
- 窗口透明度、彩虹划词窗口（换一套彩色外观）。
- 截图翻译输出：截图后的结果显示在气泡窗口还是主窗口，见 3.2。

## 3. 悬浮窗

悬浮窗是一个透明的小窗口，盖在想看的内容上，把窗口下面的文字翻译出来。按 Ctrl+Alt+G 或点托盘菜单里的「悬浮窗口」打开。

### 3.1 玻璃、置顶、散点与整段

**窗口本身**

- 拖顶部的横条移动窗口，拖边缘改大小。窗口始终在其他窗口之上。
- 点顶部的小横条调透明度；默认透明度在 设置 → 悬浮窗口 里。
- 顶部有三个模式：截图翻译、讲解、听译。听译要先下载识别模型（见 3.3）。
- 默认情况下悬浮窗对截图和录屏工具是隐身的。要把悬浮窗录进去，在 设置 → 悬浮窗口 里打开「允许悬浮窗被截图和录屏」。

**截译**

- 把窗口盖到要翻译的内容上，按空格或点相机按钮，程序识别窗口下面的文字并翻译。再按一次空格清空。
- 译文有两种显示方式：**散点**是每块文字在原来的位置上贴一块译文，适合界面、单词表、漫画；**整段**是合成一段译文，适合文章。默认「自动」按内容判断，可在 设置 → 悬浮窗口 → 显示模式 里固定。右下角的小标记会告诉你这次用的是哪种。
- 散点模式下每块译文都能拖动；双击一块，它就变成独立的小窗口，关掉悬浮窗也还在。

**自动刷新**

- 点自动刷新按钮，选间隔（2、3、5、10 秒），程序会盯着这块区域循环截译，内容没变时什么也不做。适合看直播字幕、会议字幕。
- 移动窗口、手动截译或关闭窗口都会停止自动刷新。

**鼠标穿透**

- 点穿透按钮后，点击悬浮窗的内容区会直接落到下面的程序上，比如给漫画翻页；顶部横条仍然可以点，按 Esc 退出。
- 按住 Alt 是临时穿透，松开就恢复。

**讲解模式**

- 切到「讲解」，截图后不翻译，直接把内容讲解清楚，结果显示在窗口里。需要能对话的翻译源，见 1.5。

**其他**

- Ctrl+H 打开最近的翻译记录。
- 悬浮窗默认用 设置 → OCR 识别 里选的引擎，也可以在 设置 → 悬浮窗口 里单独指定。

### 3.2 截图识别

- 按 Alt+Q，或点托盘菜单「截图翻译」、翻译面板的「截图识别」按钮。屏幕变暗后拖出一个框。多显示器都可以框。
- 默认框好后要点 ✓ 或按 Enter 确认，Esc 取消。不想每次确认，在 设置 → OCR 识别 里关掉「显示截图确认按钮」。
- 结果去哪里由 设置 → 划词翻译 → 截图翻译输出 决定：**气泡窗口**在框的旁边弹出翻译卡片，和划词的卡片一样；**主窗口**把识别出的文字填进翻译面板并翻译。
- 选定的 OCR 引擎用不了时（比如视觉模型还没装好），程序会改用本地识别，并在结果里提示。

### 3.3 听译实时字幕

把电脑里正在播放的声音实时转成字幕并翻译。音频只在内存里处理，不会保存。

**准备**

- 先到 设置 → 音频 → 听 下载「基础识别模型」。想边说边出字，再装「草稿引擎」；带音乐或噪声时想更准，装「高精度定稿引擎」并把定稿档位切到高精度。

**使用**

1. 在悬浮窗顶部切到「听译」。
2. 选声音来源：全部声音，或只听某一个程序（需要 Windows 11）。
3. 选识别语言（可以自动）和翻译目标（也可以选不翻译）。
4. 点开始。窗口里出现字幕：一行正在说的内容，说完变成定稿，下面跟着译文。左上的小条随声音跳动，告诉你声音有没有进来。
5. 鼠标放到某一行上可以朗读它；朗读时会暂停收音，说完自动恢复。
6. 点停止结束。

**字幕文件**

- 停止或切换来源时，字幕自动保存成 .srt 文件，放在程序目录的 `data\listen` 里，只保留最近 20 个。点顶部的文件夹按钮打开。无痕模式下不保存。
- 不想自动保存，在 设置 → 音频 → 听 里关掉。

**提示**

- 「未检测到声音」：检查系统音量是不是静音了。
- 「有声音，但长时间未识别到清晰语音」：换一下识别语言试试。
- 所选程序退出后，会自动切回全部声音。

## 4. 设置页

主窗口点「设置」，或按 Ctrl+4 / Ctrl+,。左栏是分页，顶部可以搜索设置项。默认是简洁目录，只列常用的几页，点左下角「完整」看全部。

大多数设置改完要点右下角的「保存更改」；主题、语言、快捷键、透明度这类改了立刻生效的项不用保存。

### 4.1 翻译源

- 上半部分是已启用的翻译源，按顺序尝试，第一个成功的就用它。拖动卡片调整顺序。
- 每张卡片：右侧开关启用 / 停用；齿轮打开配置（API 地址、密钥、模型名等），里面有「测试连接」和「获取 API Key」的链接。
- 下半部分是未启用的翻译源，点「启用」加进来。
- 卡片上的标签说明类型：AI 大模型、专业 API、传统翻译。标「无 AI 动作」的只会翻译，不能总结、讲解。
- 内置模型的卡片里能看到它现在跑在显卡还是 CPU、有没有载入、速度多少，可以自检和卸载。
- 密钥保存后会加密存在本机，设置文件里看不到明文。

### 4.2 翻译设置

- 自动翻译：停止输入后自动开始翻译，下面可以调等待时间。
- 流式输出：译文逐字显示。
- 内容已是目标语言时：显示原文，或者反过来翻成你设的源语言。对划词和悬浮窗都生效。
- 自定义语言：在语言选择器底部添加的语言都列在这里，可以删除。这些语言 Google 翻译不支持，能不能翻要看当前用的大模型。
- 翻译缓存：相同内容再翻译时直接返回结果，这里可以清除。

### 4.3 划词翻译

见第 2 章「相关设置」。

### 4.4 悬浮窗口

- 默认透明度。
- 显示模式：自动 / 散点 / 整段，见 3.1。
- OCR 引擎：默认跟随 OCR 识别页的设置，也可以给悬浮窗单独选一个。
- 允许悬浮窗被截图和录屏：默认关闭。

### 4.5 文档翻译

- 单段最大字符数：太长的段落按这个数拆开翻译。
- 同时翻译段数：并发模式下一次翻几段。本地模型建议 1 到 2，在线 API 可以调高。
- 智能过滤：跳过过短段落（可设最小字符数）、跳过纯数字段落（页码之类）、保留代码块不翻译、跳过已经是目标语言的段落。
- 默认显示样式：上下对照或左右对照。
- 下面列出支持的文件格式。

### 4.6 AI 动作

- 内置动作：总结、讲解。这里可以调「总结」出现的字数门槛，觉得该出现却没出现就调小。
- 导入的动作：点「导入配置文件」选一个 JSON 文件，可以是一个动作或一组动作，导入后保存生效。不合规的文件会被拒绝并说明原因。
- 导入的动作可以移除。

### 4.7 本地模型

程序自带的模型，文件要自己下载放进模型文件夹，见第 5 章。

- 模型：选用哪一个。通用模型能翻译也能做 AI 动作；仅翻译模型只翻译，选它时 AI 动作会自动改走别的大模型源。
- 模型文件：每个文件一张卡，显示已安装 / 未安装 / 文件不符，附官方下载和国内镜像链接。放好文件后点「重新扫描」，或「打开文件夹」直接看。
- 自定义模型（开发者）：打开后文件夹里其他 GGUF 文件也能选，可以对它们做探针、看试用报告。这些模型没有验证过，效果自己判断。

### 4.8 OCR 识别

- 识别语言：默认自动检测。中文、英文、日文和大部分拉丁语系语言内置；韩文、西里尔、天城文、阿拉伯字母等要在下方下载语言包。
- 截图选项：显示截图确认按钮；自动放大小图片，小字识别更准。
- 引擎分三组，点「使用」选一个当默认：
- **本地引擎**：本地 OCR（内置，毫秒级）和 Windows OCR（系统自带，不用下载，质量一般）。本地 OCR 下面有模型档位（标准 / 高精度，高精度对模糊照片、艺术字更强，要下载约 95 MB）、语言包列表、重新检查引擎状态。
- **视觉大模型**：内置视觉模型（两个文件按链接自取，只在显卡加速打开时可用；选它后简单截图仍走本地 OCR，大图、多栏、表格才交给它）和 LLM Vision（填 LM Studio / Ollama 的接口地址和视觉模型名）。
- **在线服务**：OCR.space、Google Vision、Azure、百度 OCR，各自填密钥。隐私模式下自动禁用。

### 4.9 音频 · 听

- 从「音频」页点「听」进入。
- 识别模型列表：基础识别模型（必需）、草稿引擎（可选，中英边说边出字）、高精度定稿引擎（可选，太大不提供下载，按链接自取后放进指定目录）。下载、更新、卸载都在这里。
- 定稿档位：标准 / 高精度。
- 停止或切换时自动保存字幕：默认开。

### 4.10 音频 · 读

- 从「音频」页点「读」进入。
- 启用文本朗读：关掉后各处的朗读按钮都不显示。
- 引擎：系统语音（不用下载）、神经语音（要装语音包，更自然）、外接服务（填了地址才出现）。
- 当前朗读：显示现在实际用的是谁，旁边可以试听。选的引擎用不了时会自动改用系统语音。
- 音色：神经语音按中文、英文分别选，点开选择器有搜索和试听；系统语音可以固定一个，或按文本语言自动选。
- 外接语音服务：填服务地址、密钥、模型、音色，点「测试并试听」。离线模式下不可用。
- 语速、音调、音量三个滑块。音调只对系统语音有效。
- 语音包：在「语音包」页签里下载和卸载。

### 4.11 界面外观

- 界面语言：中文 / English。
- 主题：默认、清新、暗色。
- 启动：开机自启动、启动后自动开启划词翻译。
- 通知：长任务完成后发系统通知。
- 快捷键：五个全局快捷键，点一个按新组合即可修改，可以重置为默认。

### 4.12 隐私模式

- 顶部三选一：标准 / 无痕 / 离线，下面列出当前模式下各功能的状态，「详细」看三种模式的完整对比。
- 数据管理：显示历史、收藏、缓存、文档进度、设置文件、日志各占多少；可以清除历史记录、清除缓存、清除所有数据；「自动删除历史记录」设天数，0 表示不删。
- 迁移：「导出迁移包」把设置、术语库、收藏、自定义语言打成一个文件；到另一台电脑「导入迁移包」，导入时可以勾选只要哪几块。API 密钥和模型文件不会进迁移包。

### 4.13 关于

- 版本号和「检查更新」。有新版本时可以直接下载安装，也可以去 GitHub 手动下载。
- 存储：数据目录和模型目录在哪里，可以打开文件夹。旧版本留在别处的模型可以「移到程序目录」，搬完后可以清理旧目录。
- 显卡加速：一个开关，打开后本地 OCR、神经语音、本地模型、内置视觉模型会在显卡上运行，每个引擎先自检，不行的自动留在 CPU，不用重启。听译识别始终在 CPU。
- 引擎状态：每个引擎现在跑在哪里、自检结果、速度。
- 打开日志目录、重置全部设置（API 密钥会保留）。

## 5. 模型与下载

程序本身不带任何模型。小的模型在设置页里一键下载；大的模型（几百 MB 到 2 GB）不经我们的服务器分发，按下面的链接自己下载，放进模型文件夹即可。所有模型都在本机运行，下载完成后不再联网。

模型文件夹在 设置 → 关于 → 存储 里能看到，可以直接打开。默认是程序安装目录下的 `models`，里面按用途分四个子文件夹：

- `llm-models`：内置模型、内置视觉模型
- `ocr-models`：OCR 语言包、高精度模型
- `asr-models`：听译识别模型
- `tts-models`：神经语音包

### 5.1 内置模型（手动下载）

把文件放进 `models\llm-models`，保持原文件名，然后到 设置 → 本地模型 点「重新扫描」。程序会校验文件内容，校验通过才会使用；显示「文件不符」就是下载不完整或版本不对，重新下载即可。

**Qwen3-1.7B**（通用，默认）：翻译加全部 AI 动作。文件 `Qwen3-1.7B-Q8_0.gguf`，约 1.8 GB，需要 8 GB 内存。

- 官方：https://huggingface.co/Qwen/Qwen3-1.7B-GGUF/resolve/main/Qwen3-1.7B-Q8_0.gguf
- 国内镜像：https://hf-mirror.com/Qwen/Qwen3-1.7B-GGUF/resolve/main/Qwen3-1.7B-Q8_0.gguf

**Hy-MT2-1.8B**（仅翻译）：只做翻译，速度和质量都好，但不能总结、讲解。文件 `Hy-MT2-1.8B-Q8_0.gguf`，约 1.9 GB，需要 8 GB 内存。

- 官方：https://huggingface.co/tencent/Hy-MT2-1.8B-GGUF/resolve/main/Hy-MT2-1.8B-Q8_0.gguf
- 国内镜像：https://hf-mirror.com/tencent/Hy-MT2-1.8B-GGUF/resolve/main/Hy-MT2-1.8B-Q8_0.gguf

**PaddleOCR-VL-1.6**（内置视觉模型）：两个文件都要放，主模型约 0.9 GB，图像编码器约 0.9 GB。只在显卡加速打开时可用。放好后到 设置 → OCR 识别 → 视觉大模型 点「重新检测」。

- 主模型官方：https://huggingface.co/PaddlePaddle/PaddleOCR-VL-1.6-GGUF/resolve/main/PaddleOCR-VL-1.6-GGUF.gguf
- 主模型镜像：https://hf-mirror.com/PaddlePaddle/PaddleOCR-VL-1.6-GGUF/resolve/main/PaddleOCR-VL-1.6-GGUF.gguf
- 图像编码器官方：https://huggingface.co/PaddlePaddle/PaddleOCR-VL-1.6-GGUF/resolve/main/PaddleOCR-VL-1.6-GGUF-mmproj.gguf
- 图像编码器镜像：https://hf-mirror.com/PaddlePaddle/PaddleOCR-VL-1.6-GGUF/resolve/main/PaddleOCR-VL-1.6-GGUF-mmproj.gguf

这些链接在 设置 → 本地模型 和 OCR 识别 页里也有，点了直接打开浏览器。三个模型都是 Apache-2.0 协议。

### 5.2 高精度听译模型（手动下载）

带音乐或噪声的声音识别更准，支持 30 种语言。约 806 MB，运行时占 1 到 1.6 GB 内存，推荐 16 GB 内存的电脑。

1. 下载：https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-qwen3-asr-0.6B-int8-2026-03-25.tar.bz2
2. 解压，得到一个名为 `sherpa-onnx-qwen3-asr-0.6B-int8-2026-03-25` 的文件夹。
3. 把整个文件夹放进 `models\asr-models`。
4. 到 设置 → 音频 → 听，点「已放好，重新检测」，再把定稿档位切到「高精度」。

### 5.3 在程序里一键下载的模型

这些在设置页里点「下载」即可，离线模式下不能下载。

- **OCR 语言包**（设置 → OCR 识别）：韩文、西里尔字母、天城文、阿拉伯字母、泰米尔文、泰卢固文、卡纳达文，每个包覆盖同一种文字的多种语言。还有高精度模型，约 95 MB。
- **听译识别模型**（设置 → 音频 → 听）：基础识别模型约 153 MB，必需；草稿引擎约 168 MB，可选。
- **神经语音包**（设置 → 音频 → 读 → 语音包）：Kokoro（103 个中英音色）和 MeloTTS（一个中英混读最自然的女声）。

程序里下载不了时（比如网络原因），可以去发布页手动下载压缩包：

- OCR 语言包：https://github.com/Tianao0110/T-Translate/releases/tag/ocr-models
- 听译模型与语音包：https://github.com/Tianao0110/T-Translate/releases/tag/audio-models

下载后把压缩包解压成一个文件夹，放进对应的子文件夹（`ocr-models`、`asr-models` 或 `tts-models`），再回设置页点「刷新」。

### 5.4 本地大模型服务

除了内置模型，也可以让程序连本机运行的 LM Studio 或 Ollama：装好软件、载入一个模型，在 设置 → 翻译源 里启用对应的翻译源就行。地址默认已经填好，用的不是默认端口再改。视觉模型（LLM Vision 引擎）也走同一个地址。

## 7. 数据放在哪里与备份

### 7.1 两个文件夹

程序的东西都在安装目录下的两个文件夹里，在 设置 → 关于 → 存储 里能看到位置，可以直接打开：

- `data`：设置、历史记录、收藏、翻译缓存、日志、自动保存的字幕。
- `models`：下载和手动放入的模型，见第 5 章。

安装目录不可写（比如装在 Program Files 里）时，程序会改用用户目录，关于页会标出来。

`data` 里常用的几项：

- `config.json`：全部设置。API 密钥也在里面，但是加密过的，看不到明文。
- `translation-data.enc`：历史记录、收藏、统计，加密保存。
- `cache\`：翻译缓存，可以随时清。
- `logs\`：日志，排查问题时用。
- `listen\`：听译自动保存的字幕文件。

### 7.2 备份与搬家

- **卸载和升级不会丢数据**：这两个文件夹会保留，重新安装后自动接上。
- **换电脑**：不要直接复制 `data` 文件夹。历史记录和 API 密钥是用这台电脑的系统密钥加密的，到别的电脑上打不开。用下面三种导出：
- 设置 → 隐私模式 → 迁移：「导出迁移包」得到一个 JSON 文件，包含设置、术语库、收藏和自定义语言；新电脑上「导入迁移包」。API 密钥不会进迁移包，要重新填。
- 历史页的「导出」把历史记录存成 JSON，新电脑上「导入」。
- 收藏页的「导出术语」单独备份术语库。
- **模型**：`models` 文件夹可以整个复制到新电脑的同一位置，省得重新下载。
- **同一台电脑重装系统**前，除了上面的导出，也可以整体备份 `data` 和 `models`；系统重装后加密的部分能不能打开取决于系统密钥是否还在，所以导出的文件才是可靠的备份。

### 7.3 清理

- 设置 → 隐私模式 → 数据管理 里可以清历史、清缓存，或「清除所有数据」。
- 设置 → 关于 里可以重置全部设置（保留 API 密钥）、清理旧版本留下的目录。
- 模型不用了，到对应的设置页点「卸载」；手动放入的文件直接从文件夹删掉即可。

## 8. 常见问题

只回答怎么用的问题。程序出错、连不上之类的排查，看 GitHub 上的 [FAQ](https://github.com/Tianao0110/T-Translate/blob/main/docs/FAQ.md)。

**怎么完全不联网使用？**
把内置模型放进模型文件夹（第 5 章），OCR 用本地引擎，然后在 设置 → 隐私模式 切到「离线模式」。之后翻译、截图识别、听译、朗读都在本机完成。

**哪些功能一定要联网？**
Google 翻译和其他在线翻译源、在线 OCR、外接朗读服务、模型下载、检查更新。其余都不需要。

**内置模型和 LM Studio / Ollama 有什么区别？**
内置模型是程序自己加载模型文件，不用装别的软件；LM Studio 和 Ollama 是你自己运行的服务，程序去连它。想省事用内置模型，想换更大的模型就用 LM Studio 或 Ollama。

**为什么没有「总结」按钮？**
两个原因：内容还不够长（门槛在 设置 → AI 动作 里调），或者当前用的翻译源不能对话（翻译源卡片上标「无 AI 动作」的都不行）。

**想让某个词一直按我的译法翻？**
把它收藏进术语库（收藏页 → 术语库），以后翻译会自动替换。

**悬浮窗挡住了我要点的东西？**
点悬浮窗的穿透按钮，内容区的点击会落到下面的程序上；临时用的话按住 Alt。

**看视频字幕用哪个？**
画面上有字幕的，用悬浮窗盖住字幕区，开自动刷新。没有字幕只有声音的，用悬浮窗的听译。

**截图翻译的结果想在主窗口里看？**
设置 → 划词翻译 → 截图翻译输出，选「主窗口」。

**要不要开显卡加速？**
有独立显卡就开：设置 → 关于 → 显卡加速。打开后每个引擎会自检，不行的自动留在 CPU，不会弄坏什么。

**快捷键和别的程序冲突了？**
设置 → 界面外观 → 快捷键，点那一项按一个新组合。

**API 密钥安全吗？**
密钥加密存在本机，不会写进迁移包，程序也不会把它发到我们这边。离线模式下连解密都不做。

**换电脑怎么把东西带走？**
看 7.2：导出迁移包、导出历史、复制 models 文件夹。不要直接复制 data 文件夹。
